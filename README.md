# Triget — Strona internetowa

Strona firmowa **Triget** — kompleksowe instalacje elektryczne dla Małopolski i Śląska.

## Struktura plików

```
Triget-Strona/
├── Triget.html          # Główna strona (HTML + CSS + JS w jednym pliku)
├── README.md            # Ten plik
├── LICENSE.md           # Licencja
└── PlikiStrona/
    ├── logo.png         # Logo firmy
    └── film triget.mp4  # Film na stronie głównej (sekcja hero)
```

## Uruchomienie lokalne

Otwórz plik `Triget.html` w przeglądarce. Upewnij się, że folder `PlikiStrona/` znajduje się w tym samym katalogu co plik HTML — inaczej logo i film nie załadują się poprawnie.

## Publikacja na serwerze

1. Wgraj cały folder `Triget-Strona/` na serwer (FTP, cPanel, Netlify, itp.)
2. Opcjonalnie zmień nazwę `Triget.html` na `index.html`, jeśli hosting tego wymaga
3. Upewnij się, że serwer obsługuje HTTPS (wymagane dla autoplay wideo w Chrome)
